```
Pour calculer des pourcentages successifs, on applique le premier pourcentage, puis à
ce résultat, on applique le second pourcentage.
```
Autrementdit,

```
Pour calculer des pourcentages successifs, il
suffit de les multiplier entre eux et non de les
ajouter!!!
```

Exemple 1 :

➢ Combien représente 15% de 20% de 350?

```
Solution 1 : 20% de 350 = 70 puis 15% de 70 = 10,
Solution 2 : 15% x 20% x 350 = 0,15 x 0,20 x 350 = 10,
```
Remarque: Si on avait fait 15% + 20% = 35% de 350 on aurait

obtenu 122,5 ce qui est faux!
